## Descripción del proyecto

Este proyecto consiste en el desarrollo y personalización de un portafolio web personal utilizando **HTML, CSS, JavaScript y Bootstrap**.

El objetivo principal es presentar de manera clara y profesional información relacionada con mi formación como estudiante de **Ingeniería en Sistemas Computacionales**, así como mis habilidades, intereses, certificaciones y trabajos realizados.

Para el desarrollo del portafolio se utilizó como base la plantilla **MyPage** de BootstrapMade. A partir de esta plantilla se modificaron textos, imágenes, secciones, habilidades, información personal y contenido para adaptarlo a mi perfil.

### Plantilla utilizada

- **Nombre:** Angel Yiban Ruiz Osante
- **Autor:** BootstrapMade
- **Framework CSS:** Bootstrap
- **Sitio oficial:** [MyPage - BootstrapMade](https://bootstrapmade.com/mypage-bootstrap-personal-template/)

---

## Tecnologías utilizadas

El portafolio fue desarrollado utilizando las siguientes tecnologías:

- **HTML5:** estructura principal del sitio.
- **CSS3:** personalización adicional de estilos.
- **JavaScript:** funcionalidades e interacción de la página.
- **Bootstrap:** framework CSS utilizado por la plantilla.
- **Bootstrap Icons:** iconos utilizados en diferentes secciones.
- **AOS:** animaciones al desplazarse por la página.
- **Glightbox:** visualización ampliada de imágenes y certificados.
- **Isotope:** organización y filtrado de elementos del portafolio.
- **Swiper:** componentes interactivos incluidos originalmente en la plantilla.

No se utilizaron frameworks de JavaScript como React o Vue.

## Proceso de creación

El desarrollo del portafolio se realizó mediante los siguientes pasos:

### Paso 1. Selección de la plantilla

Primero se analizaron diferentes plantillas de portafolio desarrolladas con Bootstrap.

Se seleccionó **MyPage de BootstrapMade** porque cuenta con una estructura adecuada para un portafolio personal y contiene secciones para presentación, información personal, habilidades, trabajos y contacto.

---

### Paso 2. Descarga y ejecución de la plantilla

Se descargó la plantilla y se abrió el proyecto utilizando Visual Studio Code.

Posteriormente se utilizó **Live Server** para visualizar el sitio localmente en el navegador y comprobar el funcionamiento de los estilos, animaciones y componentes.

---

### Paso 3. Personalización de la información

Se sustituyó la información genérica de la plantilla por información relacionada con mi perfil.

Entre los principales cambios se encuentran:

- Cambio del nombre original por mi nombre.
- Inclusión de una fotografía profesional real.
- Traducción del contenido principal al español.
- Modificación de la presentación.
- Adaptación de la sección "Sobre mí".
- Cambio de textos relacionados con diseño por información relacionada con Ingeniería en Sistemas Computacionales.

---

### Paso 4. Adaptación de habilidades

La sección de habilidades fue modificada para mostrar tecnologías y conocimientos relacionados con mi formación.

Se eliminaron habilidades genéricas de la plantilla y se agregaron tecnologías como:

- HTML y CSS.
- JavaScript.
- Python.
- PostgreSQL.
- SQL.
- Bootstrap.
- Git.
- Flask.

También se agregaron habilidades relacionadas con trabajo en equipo, resolución de problemas y aprendizaje continuo.

---

### Paso 5. Eliminación de secciones innecesarias

Algunas secciones de la plantilla original no se adaptaban al objetivo del portafolio.

Por este motivo se eliminaron:

- Servicios.
- Testimonios.
- Información profesional ficticia.
- Elementos de navegación que no serían utilizados.

Esto permitió mantener una página más limpia y enfocada en mi perfil académico.

---

### Paso 6. Personalización del portafolio

La sección de portafolio se adaptó para mostrar cursos y certificaciones.

Se reemplazaron las imágenes y textos originales por certificados relacionados con:

- Inteligencia artificial.
- Estadística.
- Datos.
- Tecnología.
- Formación profesional.

También se mantuvo la función de visualización ampliada de las imágenes.

---

### Paso 7. Organización de archivos

El proyecto se organizó para cumplir con la estructura solicitada.

Se crearon las carpetas:

```text

js/
img/
```

Dentro de ellas se encuentran:


### Paso 8. Revisión final
